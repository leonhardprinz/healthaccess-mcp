Connect an AI

Apple Health in Cursor

One entry in ~/.cursor/mcp.json, no path to type: the server finds your Health Access folder on its own. Then the agent in Cursor's chat can read your sessions and vitals and write a plan to your Watch.

Before you start

  1. The Health Access app has written files into your folder, and the folder syncs to this computer.
  2. Node.js 18 or newer is installed (npx --version prints a number).

Add the server

Global, for every project: ~/.cursor/mcp.json. For one project only: .cursor/mcp.json in that project. Same content either way.

{
  "mcpServers": {
    "healthaccess": {
      "command": "npx",
      "args": ["-y", "healthaccess-mcp"]
    }
  }
}
  • The server looks in iCloud Drive, then Dropbox, Google Drive, OneDrive and Box, then ~/Documents. To name the folder yourself, add "--dir", "/absolute/path/to/your folder" to args.
  • If Cursor reports spawn npx ENOENT, put the full path from which npx into command.
  • Cursor's settings also have an MCP section with an "add server" button that writes the same file. Either way works.

Check

Cursor Settings, the MCP section: healthaccess should show a green dot and the thirteen tools. If it is red, run the command yourself in a terminal and read the error:

npx -y healthaccess-mcp --check

Then say to it

In the chat panel, in Agent mode:

Use the healthaccess tools. List my last 5 workouts, one line each, then read the training summary for 4 weeks. Tell me how this week compares to the one before, in three sentences. Ask me how the last session felt before you judge it.

Cursor asks before each tool call unless you allow the server. If you want ideas for what to ask, the prompts work here unchanged.

Why Cursor for this at all

Because the folder is also a repository you can open. Open your Health Access folder in Cursor and the agent has the MCP tools and the raw JSON side by side: ask it to write a script over workouts/*.json, and it can test the script on the real files. The folder is the API.
