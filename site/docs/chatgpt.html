Connect an AI

Apple Health in ChatGPT

Through the files, yes. Through the MCP, not today. ChatGPT connects to MCP servers at an HTTPS URL, on some plans only, and doesn't start a program on your Mac. Health Access MCP is a program that runs on your Mac. Here's where things stand and what works.

ChatGPT's MCP support as of October 2026

  • ChatGPT can connect to custom MCP servers, but only remote ones with an HTTPS URL. It can't launch a local process over stdio, and that's how Health Access MCP (like every other local MCP server) talks to its client.
  • The plans that can add a custom MCP server have changed more than once since the feature came out in 2025. When I wrote this, OpenAI's help center listed it for Business and Enterprise/Edu workspaces, with a read-only version for Pro. to confirm Check OpenAI's article on developer mode and MCP in ChatGPT before you plan around it.
  • Health Access MCP needs no changes for ChatGPT, because the server speaks standard MCP. If OpenAI adds local servers, you'd use the Claude Desktop snippet.

Path 1: use the files (works now)

Everything the MCP serves is a plain file in the folder your phone writes to, so you can upload it to ChatGPT.

  1. The message from your phone. In the app (1.0.3 and later), go to Export, Your AI, Copy. Every AI gets the same message. Claude and Cursor use it to set up the connection, and ChatGPT is told to work from the summary in it. Paste it into a chat, or pick ChatGPT in the share sheet that opens. It's a snapshot, so copy a new one after new workouts.
  2. The briefing. briefing.md is a one-page summary the app writes after every sync: last four weeks, recent sessions, vitals, the next planned session, open items. Upload it to a conversation, or add it to a ChatGPT project so every chat there starts with it. The command line gives you the same thing: run healthaccess summary --weeks 4 and healthaccess show <id> and paste the output.
  3. One session. Upload workouts/2026-05-14_0712_PoolSwim_7A1C3E90.json (or any other workout file) and ask about it. The file has every interval, every length, the heart-rate series and your effort rating. What the fields mean.
  4. A plan back to the Watch. Ask ChatGPT to write the session in the plan format and save the JSON it gives you into plans/. The app offers "Put on Watch" within a minute. You don't need the MCP for this either, the app only needs the file.

A prompt to try:

This is my training briefing from Health Access. Read it, then ask me how I slept and how motivated I feel. After my answers, tell me whether the numbers suggest I am overdoing it, as a hypothesis with your confidence, not a verdict.

Path 2: a bridge to an HTTPS URL (not recommended)

With a stdio-to-HTTP proxy and a public tunnel, the local server gets a URL that ChatGPT can connect to. It works in principle, but I don't recommend it. Your training data then goes through a tunnel and sits behind a URL, and the server has no authentication of its own. If you do it anyway, put real authentication in front of it and take it down when you're done.

Why there's no cloud server

Running one would mean a server, an account and a copy of your health data that I'd hold. Some of the other products went that way. This one keeps your data in the folder you own.
