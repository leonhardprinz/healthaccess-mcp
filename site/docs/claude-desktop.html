Connect an AI

Apple Health in Claude Desktop

You add seven lines to Claude Desktop's config file. You don't have to type a path, because the server finds your Health Access folder on its own. After you restart Claude, it can read your Watch data.

Before you start

  1. The Health Access app has written files into your folder, and the folder syncs to this computer.
  2. You have Node.js 18 or newer (npx --version prints a number). If not, get it from nodejs.org or with brew install node.

Edit the config file

In Claude Desktop, open the Claude menu in the macOS menu bar, then Settings, the Developer tab and Edit Config. This opens the file below, or creates it if it doesn't exist yet:

~/Library/Application Support/Claude/claude_desktop_config.json

Add the server. If there are other servers in the file already, put the healthaccess entry inside the existing mcpServers object.

{
  "mcpServers": {
    "healthaccess": {
      "command": "npx",
      "args": ["-y", "healthaccess-mcp"]
    }
  }
}
  • The server looks for your folder on this computer: in iCloud Drive, then in the sync folders of Dropbox, Google Drive, OneDrive and Box, then in ~/Documents. To pick it yourself, add "--dir", "/Users/<you>/…/your folder" to args. The path must be absolute, because nothing expands ~ here.
  • If Claude reports spawn npx ENOENT, it can't see your shell's PATH. Run which npx in Terminal and put that full path into command.
  • Quit Claude Desktop completely and start it again. It only reads the config when it starts.

Check that it works

In a new conversation, open the attachments menu at the bottom left of the input box, then Connectors. When it works, healthaccess is in the list with its tools. If it isn't, run these:

npx -y healthaccess-mcp --check     # prints the folder it found and where from
tail -n 40 ~/Library/Logs/Claude/mcp-server-healthaccess.log

A first prompt to try

Use Health Access to list my last 5 workouts, one line each. Then read my training summary for the last 4 weeks and tell me one thing that went well, with a number, and one thing you would change. Ask me how the last session felt before you decide.

Claude Desktop asks for permission the first time each tool runs. For more ideas, you can paste any of the prompts here as they are.

Use it without the MCP

You can also add files to a Claude Project. If you drop briefing.md from the folder into a project, every conversation in it starts with your last four weeks. The workout JSON files work the same way, one file per session.

From app version 1.1.0, there is one more way. Switch on Cloud upload in the app, and the app uploads the folder to Google Drive. Then Claude can read it through its Google Drive connector, even where Claude can't start a local program. How Cloud upload works.
