Connect an AI

Apple Health in Claude Desktop

Seven lines in Claude Desktop's config file, no path to type: the server finds your Health Access folder on its own. Restart Claude, and your Watch data is in the conversation.

Before you start

  1. The Health Access app has written files into your folder, and the folder syncs to this computer.
  2. Node.js 18 or newer is installed (npx --version prints a number). If not: nodejs.org or brew install node.

Edit the config file

In Claude Desktop: the Claude menu in the macOS menu bar, Settings, the Developer tab, Edit Config. That opens, or creates, this file:

~/Library/Application Support/Claude/claude_desktop_config.json

Add the server. If the file already has other servers, add the healthaccess entry inside the existing mcpServers object.

{
  "mcpServers": {
    "healthaccess": {
      "command": "npx",
      "args": ["-y", "healthaccess-mcp"]
    }
  }
}
  • The server looks for your folder in iCloud Drive, then Dropbox, Google Drive, OneDrive and Box, then ~/Documents. To name it yourself, add "--dir", "/Users/<you>/…/your folder" to args; the path must be absolute, ~ is not expanded here.
  • If Claude reports spawn npx ENOENT, it cannot see your shell's PATH. Run which npx in Terminal and put that full path into command.
  • Quit Claude Desktop completely and start it again. The config is read at launch.

Check

In a new conversation, open the attachments menu at the bottom left of the input box, then Connectors. healthaccess should be listed with its tools. If it is not:

npx -y healthaccess-mcp --check     # prints the folder it found and where from
tail -n 40 ~/Library/Logs/Claude/mcp-server-healthaccess.log

Then say to it

Use Health Access to list my last 5 workouts, one line each. Then read my training summary for the last 4 weeks and tell me one thing that went well, with a number, and one thing you would change. Ask me how the last session felt before you decide.

Claude Desktop asks for permission the first time each tool runs. If you want ideas for what to ask, the prompts can be pasted here as they are.

Without the MCP

Claude Projects take files. Drop briefing.md from the folder into a project and every conversation in it starts with your last four weeks. The workout JSON files work the same way, one session each.
